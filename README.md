# Fantacalcio 2026/27

Repository operativo per costruire un sistema decisionale completo orientato a massimizzare la probabilità di vittoria in una lega Fantacalcio Classic 2026/27.

## Come riprendere il progetto

In una nuova chat o con un nuovo agente AI è sufficiente indicare questo repository e chiedere di continuare.

L'agente deve leggere, nell'ordine:

1. `AGENTS.md` — regole operative persistenti e comportamento richiesto;
2. `PROJECT.md` — obiettivo, contesto, decisioni, stato e prossimo outcome;
3. gli artefatti specifici necessari al prossimo lavoro.

Non deve essere necessario ricostruire la conversazione precedente né ridefinire il metodo di lavoro.

## File canonici

- `AGENTS.md`: come lavorare sul progetto.
- `PROJECT.md`: cosa stiamo costruendo e a che punto siamo.

Gli altri file e directory verranno creati solo quando servono a un output concreto di ricerca, dati, modellazione, asta o consegna finale.

## Stato attuale

Il prossimo outcome canonico è registrato in `PROJECT.md`. Fare sempre riferimento a quello invece di ricominciare una discovery generale del progetto.
